bartleby["]

tools

every tool runs on your device. nothing is uploaded.

about

bartleby turns short videos into text. paste a link, get the transcript.

the listening and writing happen on your own device, so nothing you paste is uploaded or kept.

there are no ads, no signup and no tracking. he would prefer not to.

named after the copyist in herman melville's 1853 story, who met every request with the same five words. this one sighs first, then does the job.

this is v1.0, the mvp. what works so far

Built by Zach Doxsee

supported

by link

    by file

    • any audio or video file dropped on the page, or picked with the file button
    • tiktok videos save the video in the app first; tiktok makes visitors log in before it shows one

    private or deleted posts can't be fetched. he will tell you, flatly.

    terminal

    the same tool as a command, for people who live in one.

    $ npm i -g bartleby
    $ bartleby https://instagram.com/reel/...
( -_- ) ugh. fine.
[ok] 87 words, saved to reel.md

    not published yet. the install command above is what it will be.

    source

    free and open source. read it, fork it, run your own.

    $ git clone https://github.com/zachdoxsee/bartleby

    the repository isn't public yet; the address above is a placeholder.

    set up with an agent

    give this to a coding agent, such as claude code, and it will get bartleby running on your machine.
